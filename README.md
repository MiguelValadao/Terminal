### O que é este projeto?

Este é um portfólio interativo em formato de terminal, desenvolvido com HTML, CSS e JavaScript.
O projeto simula um ambiente de linha de comando, permitindo a execução de comandos nativos que retornam diferentes outputs.

Todas as informações necessárias para a navegação e compreensão estão integradas ao próprio portfólio.

---

### What is this project?

This is an interactive terminal-style portfolio built with HTML, CSS, and JavaScript.
The project simulates a command-line environment, allowing users to execute native commands that display different outputs.

All the information needed for navigation and understanding is embedded within the portfolio itself.
